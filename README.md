
## Workflow Playground

A simple static site for practicing GitHub Actions and GitHub Pages deployments.

## What is included

* A single-page static website in `index.html`
* A GitHub Actions workflow in `.github/workflows/deploy.yml`
* A minimal setup that is easy to modify for workflow practice
