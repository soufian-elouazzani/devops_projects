DevOps portfolio

One service, from a host to a blue-green release.

A personal lab. The same application exposes /health, /version, and /metrics. Infrastructure, configuration management, Kubernetes, and Prometheus all speak that contract. The repository is the long form.

What is in the repository

  1. Host health snapshotRead-only Linux report with thresholds and a JSON mode.
  2. AnsibleRoles for a baseline, a systemd service, and nginx. Idempotent, with handlers.
  3. Terraform on AWSVPC, private instances, an ALB with blue and green weights, IMDSv2, SSM instead of SSH.
  4. Blue-green, runnable locallyThe idle copy is health-checked before nginx moves. Rollback is a pointer change.
  5. KubernetesProbes, HPA, disruption budgets, a network policy, and a Service selector as the cutover.
  6. Prometheus and GrafanaA scrape, two alert rules, and a dashboard that lives in Git.
  7. GitOpsAn Argo CD application. The cutover belongs in Git, or the controller will treat a patch as drift.
